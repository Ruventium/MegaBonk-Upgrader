Мод для **MegaBonk** (Unity 2023.2.22f1 IL2CPP / BepInEx 6), добавляющий новый отдельный легендарный пассивный предмет — **«Апгрейдер» (Upgrader)** с интерактивным модальным интерфейсом рулетки, ставками золотом и динамической оценкой редкости предметов.

---

## 🌟 Возможности и механика

- **Новый легендарный предмет:**
  - Добавляется как самостоятельный пассивный предмет (`eItem = 1000`) с уникальной процедурной иконкой.
  - Корректно интегрирован в пул сундуков забега (`RunUnlockables.availableItems`) с лимитом выпадений за забег (по умолчанию 1 шт.).
  - Не выдается автоматически на старте и не спамит интерфейсом при подборе.

- **Модальное окно с полной остановкой времени:**
  - Открывается только по нажатию настроенной горячей клавиши (по умолчанию `F8`) и только если у игрока есть хотя бы один «Апгрейдер».
  - Полностью замораживает игровое время, таймеры забега, мобов и снаряды (`MyTime.Pause()`, `Time.timeScale = 0f`).
  - Освобождает курсор мыши (`Cursor.lockState = None`).
  - Корректно закрывается по `Escape`, кнопке `✕` или повторному нажатию хоткея, восстанавливая захват мыши и плавное управление камерой (`Cursor.lockState = Locked`).
  - Если игра уже на паузе, модальное окно безопасно отклоняет открытие.

- **Динамическая истинная редкость (Dynamic Rarity):**
  - Оценивает реальную силу и ценность предметов на основе их лимитов выпадения (`maxAmountPerRun`) и уникальности.
  - Предметы с лимитом `1 шт. за забег` (например, *Наковальня* или *Золотая перчатка*), даже если номинально отмечены игрой как Обычные или Редкие, динамически получают высокий истинный ранг (Эпический / Легендарный) и соответствующую ценность.
  - В карточках и списках отображается как номинальная редкость, так и значок `★ Истинный ранг`.

- **Ставки золотом (Gold Betting):**
  - Игрок может поставить монеты из текущего забега (`0 🪙`, `50 🪙`, `150 🪙`, `МАКС`), чтобы повлиять на рулетку.
  - **Бонус к шансу:** ставка дает до **+15%** к вероятности успеха (сбалансировано, не превышает глобальный лимит `MaximumChance`).
  - **При победе:** игрок получает целевой предмет, а также возвращает ставку с **+50% чистой прибыли в золоте** и звуком монет.
  - **При поражении:** исходный предмет сгорает, а поставленное золото теряется.

- **Интерактивная рулетка:**
  - Плавное, зрелищное вращение (4.2 сек.) с реалистичным кубическо-квинтическим замедлением к победному слоту.
  - Звук щелчков тихий (10% от исходного по умолчанию) и автоматически масштабируется ползунком громкости эффектов (SFX) в настройках игры.
  - Золотой индикатор-указатель по центру барабана.
  - Карточка сгорания со специальным оформлением при поражении.

- **Современный Dark UI:**
  - Отображение полного описания пассивок (`GetDescription()`) в карточках предпросмотра.
  - Быстрые вкладки фильтрации по редкостям: `Все`, `Обычные`, `Редкие`, `Эпические`, `Легендарные`.
  - Отсутствие стрипнутых вызовов `GUI.TextField` (100% стабильность на релизном IL2CPP Unity).

## ⚙️ Конфигурация (`BepInEx/config/codex.megabonk.upgrader.cfg`)

| Секция | Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|---|
| `[General]` | `OpenKey` | KeyCode | `F8` | Клавиша открытия интерфейса Апгрейдера |
| `[Item]` | `ItemName` | string | `Upgrader` | Отображаемое название предмета |
| `[Item]` | `ItemDescription` | string | `...` | Описание предмета в подсказках |
| `[Item]` | `ItemRarity` | EItemRarity | `Legendary` | Редкость предмета в сундуках |
| `[Item]` | `MaxPerRun` | int | `1` | Макс. количество выпадений за забег |
| `[Roll]` | `MinimumChance` | float | `0.05` | Минимальный шанс успеха (0.05 = 5%) |
| `[Roll]` | `MaximumChance` | float | `0.90` | Максимальный шанс успеха (0.90 = 90%) |
| `[Roll]` | `SourceValueMultiplier` | float | `0.90` | Множитель ценности исходного предмета |
| `[Roll]` | `RollDuration` | float | `4.2` | Длительность вращения рулетки в секундах |
| `[Roll]` | `TickVolumeMultiplier` | float | `0.10` | Громкость щелчков рулетки (0.10 = 10% громкости) |
| `[Roll]` | `UseDynamicRarity` | bool | `true` | Расчет динамической истинной ценности по дефицитности предметов |
| `[Betting]` | `EnableGoldBetting` | bool | `true` | Включить систему ставок внутриигровым золотом |
| `[Betting]` | `MaxGoldChanceBonus` | float | `0.15` | Максимальный бонус к шансу за ставку золотом (+15%) |
| `[Betting]` | `MaxGoldBet` | int | `500` | Максимальный размер ставки золотом |
| `[Debug]` | `EnableDebugKeys` | bool | `true` | Включить хоткеи для быстрого тестирования |
| `[Debug]` | `DebugGrantKey` | KeyCode | `F9` | Выдать 1 Апгрейдер в инвентарь игрока |
| `[Debug]` | `DebugGrantPassiveKey` | KeyCode | `F10` | Выдать случайную пассивку из сундука в инвентарь |

## 🎮 Управление по умолчанию

- **F8** — открыть / закрыть интерфейс Апгрейдера (требуется наличие Апгрейдера в инвентаре).
- **Escape** — закрыть окно Апгрейдера и возобновить игру.
- **F9** *(Debug)* — получить 1 Апгрейдер для тестирования.
- **F10** *(Debug)* — получить тестовую пассивку для улучшения.
- **F11** *(Debug)* — запустить автоматический 10-шаговый стресс-тест мода в консоли BepInEx.

## 📦 Установка

1. Установите [BepInEx 6 IL2CPP](https://builds.bepinex.dev/projects/bepinex_be) (версия `x64` для Unity 2023.2).
2. Поместите файл `MegaBonkUpgrader.dll` в папку:
   ```text
   Megabonk/BepInEx/plugins/
   ```
3. Запустите игру.

---

## 🛠️ Сборка из исходников

```bash
git clone https://github.com/Ruventium/MegaBonk-Upgrader.git
cd MegaBonk-Upgrader
dotnet build -c Release
```

Собранная библиотека появится в `bin/Release/net6.0/MegaBonkUpgrader.dll`.
